## Phase 10 — Parent app on the phone — done 2026-10-25 (started 2026-10-23; notes kept)
Same workflow (show every migration, wait for OK, commit + push each step, test in Chrome AR + FR). Decisions (user, 2026-10-22 / 2026-10-23): free Web Push only (no WhatsApp, no paid SMS); pushes for **absences (+ corrections), remarks and announcements**, each type switchable by the parent; library **`web-push`** (server only).
Steps: 1 installable app (manifest, maskable icon, service worker, offline page) · 2 install card (Android prompt) + iPhone guide · 3 `push_subscriptions` in the DB + VAPID keys (user sets them in Vercel) · 4 sending (absence / remark / announcement → push, tap opens the right page, dead subscriptions removed) · 5 parent on / off per type + "Tester" · 6 closing pass (Android + iPhone 16.4+ installed).
- **Step 1 — done 2026-10-23 (no migration):** `public/manifest.webmanifest` (`id` / `start_url` `/start`, `scope` `/`, icons 192 / 512 `any` + `tasyir-icon-maskable-192|512.png` = the icon at 84 % on the brand green, full bleed). `public/sw.js` keeps NO school data: on install it caches `/ar|fr|en/offline` + the CSS / woff2 they reference (`tasyir-offline-v1`); a page navigation that fails → the offline page of the URL's language; `/_next/static` falls back to that cache. **Changing the offline page or its look: bump `CACHE`** (a byte-identical sw.js is never re-installed). - **Step 4 — done on DEV 2026-10-24 (migration `phase10_push_sending`, `20261024040000`, DEV applied by the user through the SQL editor; tests 26 / 26 + 6 / 6; production live 2026-10-24, kick → 200, real phone push received + tap OK):** nothing that creates notifications changed.
