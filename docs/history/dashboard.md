## School dashboard (2026-10-26, outside the phases; user-approved layout)
`/dashboard` for staff (teachers keep `TeacherHome`; a role allowed none of the cards keeps `WelcomePlaceholder`). Data `getDashboard()` (`src/lib/dashboard/director.ts`, session + RLS; each block only with its permission + module, else null): **attendance** (attendance.view | manage + module attendance) = tiles absent today (DISTINCT students, sessions missed in small text), late today, overdue roll calls (today's lessons of the current year started ≥ 15 min ago — `ROLL_CALL_GRACE_MINUTES` — without an attendance session; teacher names from `timetable_teachers()`; lessons read with `readAll`), justifications pending; "Cette semaine" = Monday → today vs the same days last week (marks; change in % with an icon + words); top 5 classes by absence marks, last 30 days. **grades** (grades.view | manage + module grades) = per-class entry progress of the semester holding today (least complete first) + publications (period not locked → nothing to publish; locked → classes not published). **counts** = students enrolled this year (students.view), classes, active teachers (users.view or teachers.manage). Periods from the DATABASE clock (`schoolClock()`, Africa/Casablanca): `dashboardRanges(today)` (`src/lib/dashboard/ranges.ts`, pure: today / week / lastWeek / last30) + `startedAtLeast()`. UI `src/components/features/dashboard/` (`DirectorDashboard`, `dashboard-parts.tsx`: `StatTile` `data-dashboard-tile` / `data-value` (a "#…" href renders a plain `<a>`), `DashCard` `data-dashboard-card`, `BarList` single-hue bars `data-bar-row` / `data-bar-value`, a zero draws no bar, rows ≥ 44 px), phone = one column in priority order, lg = 3 columns via `lg:order-*`. Percentages / signed changes go through `ltr()` (Arabic). Texts `dashboard.*` (2719 keys each).
